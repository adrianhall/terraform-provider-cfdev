# 002 — Provider configuration and authentication

## Introduction

Implement provider configuration, authentication, the production API default, and optional endpoint configuration.

## Details

Validate the foundation baseline first. Write tests for required and optional attributes, the default production endpoint, alternate `cloudflare_api_endpoint`, token redaction, and environment-variable authentication. Implement the typed Cloudflare client factory and provider configuration.

Run the standard TDD, green-test, format, lint/check, full-test, coverage, review, and conventional-commit loop. Commit with `feat(provider): add cfdev configuration and authentication`.

## Acceptance Criteria

- `cloudflare_api_token` is accepted securely and never appears in diagnostics.
- `cloudflare_api_endpoint` defaults to production and supports alternate compatible endpoints.
- Environment authentication behavior is tested.
- Client creation is typed and injectable for later seams.
- Checks pass and provider coverage meets the 80% target.
- The specified conventional commit is created.
