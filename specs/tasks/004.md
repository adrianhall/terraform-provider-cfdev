# 004 — Wrangler-compatible ordering and identity

## Introduction

Match Wrangler 4.151.0 migration ordering and relative-path identity semantics.

## Details

Validate discovery behavior against the pinned Wrangler version. Write tests for numeric-prefix ordering, nonnumeric names, mixed case, nested segments, path-depth ties, and relative-path identifiers. Implement the comparator and identity rules.

Run the standard delivery loop and commit with `feat(files): match wrangler migration ordering`.

## Acceptance Criteria

- Leading numeric prefixes are compared numerically by path segment.
- Numeric segments sort before nonnumeric segments.
- Remaining comparisons use byte-wise lexical ordering and path depth rules.
- Nested migration identifiers are normalized paths relative to `migrations_dir`.
- Cases such as `2_second.sql`, `10_tenth.sql`, and `alpha.sql` match Wrangler.
- Tests, checks, and coverage pass.
