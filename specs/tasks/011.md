# 011 — Acceptance and compatibility verification

## Introduction

Verify remote D1 behavior against a disposable Cloudflare account and database.

## Details

Validate unit/resource coverage and dedicated test-account safeguards. Write gated acceptance tests for Wrangler interoperability, multiple applies, custom tables, failure/retry behavior, and endpoint handling. Implement fixtures, cleanup, and CI gating. Keep acceptance tests separate from the 80% unit-coverage target.

Run the standard delivery loop and commit with `test(acceptance): verify remote d1 migration behavior`.

## Acceptance Criteria

- Acceptance tests are opt-in and cannot target production accidentally.
- Tests create and clean up disposable databases.
- Real migration application, repeat apply, new migration, custom table, and failure/retry cases are covered.
- Wrangler compatibility is verified against the pinned version.
- Unit coverage remains at or above 80%.
- Checks and the conventional commit are complete.
