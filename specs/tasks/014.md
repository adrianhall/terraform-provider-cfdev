# 014 — Documentation set and contribution policy scaffolding

## Introduction

Create the repository documentation set and contribution policies required for a Terraform provider.

## Details

Validate examples, generated docs, and release metadata. Write link and configuration checks. Add `CONTRIBUTING.md` stating that contributions are accepted through pull requests only and every PR must reference an issue; add `RELEASING.md`, `SECURITY.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md`, and the `CHANGELOG.md` policy.

Run the standard delivery loop and commit with `docs(repo): add contribution and maintenance documentation`.

## Acceptance Criteria

- README explains installation, authentication, usage, lifecycle, compatibility, and limitations.
- CONTRIBUTING requires an issue and PR-based contribution.
- RELEASING covers tags, signing, GoReleaser, Registry publication, and recovery.
- Security, support, conduct, and changelog policies exist.
- Links and referenced commands are checked.
- Tests, checks, coverage, and commit pass.
