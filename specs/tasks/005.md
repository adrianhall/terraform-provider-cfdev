# 005 — Migration hashing and changed-file detection

## Introduction

Create a deterministic migration-set hash and detect changes that require Terraform planning or diagnostics.

## Details

Validate discovery and ordering baselines. Write tests for stable hashes and changes caused by additions, removals, renames, content edits, pattern changes, table changes, and platform-independent path separators. Implement canonical hashing and applied-file drift diagnostics.

Run the standard delivery loop and commit with `feat(files): add migration set hashing`.

## Acceptance Criteria

- Identical migration sets produce identical hashes.
- Add, remove, rename, content, pattern, and table changes alter the hash.
- Canonicalization is stable across operating systems.
- Applied migration content changes are reported clearly and are not silently reapplied.
- Tests, checks, and 80% coverage target pass.
