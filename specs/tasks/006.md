# 006 — D1 SQL client seam

## Introduction

Implement the typed Cloudflare D1 client interface needed by the migration resource.

## Details

Validate provider authentication and test doubles. Write HTTP contract tests for authentication, endpoint selection, request encoding, response decoding, API errors, rate limits, retries, and redaction. Implement the minimal typed D1 client behind an injectable interface.

Run the standard delivery loop and commit with `feat(d1): add typed D1 client`.

## Acceptance Criteria

- Client requests use configured credentials and endpoint.
- Request and response types are explicit and testable.
- API, authentication, authorization, and rate-limit errors are actionable.
- Retry behavior is bounded and tested where appropriate.
- Secrets and SQL parameters are redacted.
- Tests, checks, and coverage pass.
