# 003 — Migration discovery and path normalization

## Introduction

Implement deterministic migration file discovery using the default pattern and custom Wrangler-compatible patterns.

## Details

Validate provider configuration and coverage. Write failing tests for `${migrations_dir}/*.sql`, custom patterns, required directory prefixes, regular-file filtering, nested paths, `/` normalization, and missing or invalid directories. Implement the file discovery seam.

Run the standard delivery loop and commit with `feat(files): implement migration discovery`.

## Acceptance Criteria

- Default discovery selects SQL files under `migrations_dir`.
- Custom patterns must begin with `${migrations_dir}/`.
- Nested paths are supported when selected by the pattern.
- Directory entries and unsupported file types are excluded.
- Migration paths are normalized consistently across platforms.
- Tests, checks, and 80% coverage target pass.
