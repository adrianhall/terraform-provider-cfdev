# 010 — Terraform create, update, read, and no-op delete

## Introduction

Implement the complete Terraform resource lifecycle for applying D1 migrations.

## Details

Validate the planned resource contract. Write lifecycle tests for initial apply, no pending migrations, newly added migrations, changed applied files, missing tables or databases, refresh drift, partial failure, retry, and no-op delete. Implement lifecycle methods and diagnostics.

Run the standard delivery loop and commit with `feat(resource): implement d1 migration lifecycle`.

## Acceptance Criteria

- Create and update apply only unapplied migrations.
- Read refreshes state and reports drift without applying SQL.
- Failed migrations are not recorded as successful.
- Missing or inaccessible resources produce actionable diagnostics.
- Delete removes Terraform state only and performs no destructive remote operation.
- Tests, checks, and coverage pass.
